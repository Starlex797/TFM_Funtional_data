Comparativa entre tu TFM y el trabajo de Wong/He

Diferencias metodologicas entre el proyecto TFM_Funtional_data y stfusion-main, con una seccion especifica sobre el tratamiento del spatial misalignment.

1. Resumen ejecutivo

Los dos trabajos usan una idea comun: modelos bayesianos espacio-temporales con INLA-SPDE para representar un campo latente continuo. Sin embargo, no resuelven exactamente el mismo problema.

Tu TFM

Modeliza NO2 medido en estaciones usando covariables de trafico y meteorologia. El SPDE captura la estructura espacial residual del NO2 que no explican las covariables.

Wong/He stfusion

Fusiona dos fuentes de una misma variable ambiental: clorofila in situ puntual y clorofila satelital areal. Ambas observan el mismo campo latente de clorofila.

La diferencia central es esta: en tu TFM hay una respuesta principal, el NO2, y varias covariables. En Wong/He hay dos respuestas observadas de la misma variable, con distinto soporte espacial, mas covariables ambientales.

4. Flujo de trabajo en tu TFM

Preparacion de NO2

Se limpian datos de contaminacion y se generan escalas horaria, diaria y mensual. La respuesta se transforma como log(NO2 + 1).

Armonizacion espacial de covariables

Las estaciones de NO2 se asocian a distrito y barrio mediante interseccion espacial. El trafico se une por barrio y tiempo. El clima se interpola hacia las coordenadas de las estaciones mediante IDW.

Dataset maestro

Se crea una tabla comun estacion-fecha-hora con NO2, trafico, clima, barrio, distrito y coordenadas.

Seleccion de covariables

Se estandarizan covariables, se revisa multicolinealidad con VIF, se usan residuos parciales y se seleccionan variables mediante significancia bayesiana y DIC.

Modelo INLA-SPDE

Se construye una malla sobre las estaciones, se define un campo Matern SPDE y se proyecta el campo a las estaciones con una matriz A.

Modelo espacio-temporal

Si los residuos presentan autocorrelacion, se introduce AR(1) en el campo latente.

log(NO2_i,t + 1) = beta0 + beta1 X1_i,t + ... + betaK XK_i,t + u(s_i,t) + error_i,t

5. Flujo de trabajo en Wong/He stfusion

Dos observaciones de la misma variable

El proyecto trabaja con clorofila-a observada por muestras in situ y por imagenes satelitales.

Preparacion del dominio

Se define el Western Basin de Lake Erie, se crea una rejilla satelital y se identifican las celdas con informacion valida.

Malla SPDE

Se construye una malla triangular con inla.mesh.2d(). La malla no es para las covariables, sino para el campo latente comun de clorofila.

Matriz puntual

Para los datos in situ se crea Apt, que proyecta el campo SPDE desde la malla a las coordenadas puntuales de las muestras.

Matriz areal

Para los datos satelitales se crean poligonos/celdas y una matriz Aat, que representa el campo promedio o agregado sobre cada area satelital.

Union mediante INLA stack

Se crean dos stacks: stk.pt para puntos y stk.at para areas. Luego se combinan en stk.full.t. Ambos comparten el mismo campo latente f(s, model = spde, group = s.group, AR1).

log(chla) = intercept + a_fuente + beta1 lon + beta2 lat + wind + air_temp + surface_temp + u(s,t) + error

6. Como se soluciona el misalignment en cada proyecto

6.1. Que significa misalignment

Hay spatial misalignment cuando las variables no estan medidas en el mismo soporte espacial. Por ejemplo, una estacion es un punto, un barrio es un poligono, una celda satelital es un area y una estacion meteorologica es otro punto distinto.

6.2. En Wong/He

El misalignment se resuelve dentro del modelo, porque tienen dos observaciones de la misma variable ambiental con soportes distintos:

Fuente Soporte Como entra en el modelo
Clorofila in situ Punto Apt * w: el campo latente se evalua en coordenadas puntuales.
Clorofila satelital Area/celda Aat * w: el campo latente se agrega o promedia dentro de poligonos/celdas.

La clave es que ambas fuentes observan el mismo campo latente w(s,t), pero cada una lo observa mediante una matriz de proyeccion distinta. Esto es una solucion formal de misalignment punto-area.

y_in_situ = A_punto * w + covariables + error y_satelite = A_area * w + sesgo_fuente + covariables + error

6.3. En tu TFM

En tu proyecto el misalignment se resuelve principalmente antes del modelo, en la construccion del dataset maestro:

Fuente Soporte original Solucion actual
NO2 Estaciones puntuales Es la respuesta. El SPDE se proyecta directamente a las coordenadas de las estaciones.
Trafico Detectores, barrios o distritos Se agrega por barrio y se une a cada estacion segun el barrio donde cae la estacion.
Meteorologia Estaciones meteorologicas Se interpola hacia las estaciones de NO2 mediante IDW.
Campo espacial residual Proceso continuo no observado Se modeliza con SPDE y se evalua en estaciones mediante matriz A.

Por tanto, tu solucion actual es una armonizacion espacial previa: conviertes trafico y clima en covariables disponibles en cada estacion de NO2. Luego el modelo INLA-SPDE trabaja con esa tabla comun.

log(NO2_estacion,t + 1) = covariables_ya_armonizadas_estacion,t + A_estaciones * w + error

6.4. Diferencia esencial

Wong/He resuelve el misalignment dentro del likelihood, porque tiene dos respuestas de la misma variable con distinto soporte. Tu TFM lo resuelve antes del modelo, construyendo covariables compatibles con las estaciones de NO2. Despues el SPDE captura la dependencia espacial residual.

7. Que parte de Wong/He estas adaptando realmente

Tu TFM se parece a Wong/He en la parte de modelo latente gaussiano:

  • uso de INLA;
  • uso de SPDE para aproximar un campo Matern;
  • uso de matriz A para conectar malla y observaciones;
  • posible estructura temporal AR(1);
  • covariables ambientales dentro del predictor lineal.

Pero no estas haciendo la misma fusion, porque no tienes dos mediciones de NO2 con distinto soporte. Tu trabajo es mas exactamente un modelo espacio-temporal de NO2 con covariables y campo residual SPDE.

Una frase defendible para el TFM seria:

Este TFM adapta el componente INLA-SPDE del enfoque de He y Wong, utilizando un campo latente Matern para capturar la dependencia espacial residual del NO2. A diferencia del modelo de fusion punto-area del articulo, aqui las covariables de trafico y meteorologia se armonizan previamente al soporte de las estaciones de calidad del aire.

8. Si quisieras parecerte mas a stfusion

Para acercarte mas al enfoque de Wong/He, tendrias que introducir matrices de proyeccion mas explicitas para las fuentes desalineadas. Por ejemplo:

Opcion Que cambiaria Dificultad
Pesos por distancia para trafico En vez de asignar el trafico del barrio, calcularias trafico ponderado por detectores cercanos. Media
Buffers alrededor de estaciones Calcularias trafico medio dentro de 250 m, 500 m o 1 km alrededor de cada estacion. Media
Matriz punto-area formal Representarias barrios/distritos como areas y estaciones como puntos, usando pesos de solapamiento o proximidad. Alta
Fusion real de NO2 Necesitarias otra fuente que mida NO2, por ejemplo producto satelital, modelo quimico o reanalisis. Alta

La mejora mas razonable para tu TFM seria la primera o segunda: construir covariables de trafico locales alrededor de cada estacion. Eso mantiene tu modelo manejable y hace mas solida la explicacion del misalignment.

9. Conclusion

Tu proyecto y el de Wong/He comparten la base INLA-SPDE, pero no tienen exactamente el mismo tipo de fusion. Wong/He fusiona dos observaciones de una misma variable ambiental, una puntual y otra areal. Tu TFM modeliza una unica respuesta, NO2, con covariables desalineadas que se armonizan previamente al soporte de las estaciones.

La comparacion correcta no es decir que tu TFM copia el modelo completo de Wong/He, sino que adapta su idea central: usar un campo latente espacio-temporal para representar la dependencia espacial no observada, incorporando covariables ambientales dentro de un modelo bayesiano ajustado con INLA-SPDE.
